Feature & Technology Report

What each feature does, how it works, and why it is included.

Features

FeatureWhat it doesHow it worksWhy it helps
Image upload and previewAccepts JPG, PNG, or WEBP up to 15 MB.React validates and previews; FastAPI validates again.Confirms the chosen image and rejects unsupported files.
Image summary and Q&ADescribes a scene and answers an optional question.FastAPI sends the image and prompt to an OpenRouter vision model.Provides a quick summary and targeted answers.
AI-origin cluesGives a cautious estimate of possible AI generation.The model is asked to cite visible clues and uncertainty.Provides context without claiming to prove provenance.
Free-model fallbackTries four image-capable free routes in order.Backend filters out non-free model IDs and retries busy or incomplete routes.Keeps requests on free routes and handles provider outages.
Copy or download analysisCopies the result or saves it as a text report.Uses the browser Clipboard API and a generated text file.Makes results easy to keep or share.
3D reconstructionCreates a point cloud or mesh from 5–30 overlapping product photos.FastAPI runs the local COLMAP photogrammetry engine.Combines multiple views into an inspectable model.
360° viewerRotates and zooms the model.A custom Canvas viewer projects model points and rotates on drag.Allows inspection from different angles in the browser.
Dimension calibrationEstimates length, width, and height in centimeters.Select two points and enter their known real-world distance.Scales the model; results are approximate.
PLY downloadExports a reconstructed model.The backend returns the generated PLY file.Lets users continue in a 3D editor.
Sample 3D demoShows a ceramic mug in the viewer.The browser generates synthetic geometry.Demonstrates viewer controls without a reconstruction.
Status and file checksShows API, AI, and COLMAP readiness.The UI polls status endpoints; backend validates uploads.Surfaces setup problems and invalid inputs.

Technology used

FrontendReact, Vite, CSS, and Lucide React icons.
BackendPython FastAPI for analysis, uploads, status, and downloads.
Vision AIOpenRouter chat completions with image input and four free fallback routes.
3D processingCOLMAP photogrammetry, with local image/model storage.
3D displayCustom browser Canvas viewer for rotation, zoom, and point selection.

Important limits

  • AI-origin output is an estimate from visual appearance, not proof.
  • Photos alone do not establish real-world scale. Calibration needs a known distance between two selected points.
  • The sample mug model is synthetic, not reconstructed from an uploaded photo.
  • Image analysis sends the image to OpenRouter; the API key stays on the backend.
  • Free model providers may be rate-limited; the app tries another configured free route.
